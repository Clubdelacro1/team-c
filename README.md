# TEAM C · Cocina de eventos

Recetario con gramajes por persona, menú por evento, lista de compras con presupuesto, limpieza, personal y utensilios.

- App: https://clubdelacro1.github.io/team-c/
- Datos: Supabase (esquema `teamc`). Cualquiera con el link puede ver; para editar hay que entrar con un mail autorizado.
- Se instala en el celular desde el navegador: "Agregar a pantalla de inicio".
